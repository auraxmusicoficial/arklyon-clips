# Privacy Policy — Vault Clips Uploader

Vault Clips Uploader is a private tool used only by the owner of the HQ Vault Clips channel to publish and update videos on the owner's own YouTube channel.

- It accesses the YouTube Data API only to upload videos, set thumbnails and edit titles, descriptions and tags on the owner's channel.
- It does not collect, store, sell or share personal data from any other user.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: open an issue in this repository.
